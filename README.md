# Jump And Start
### A Platformer Game Made with Godot!!
#### Collect Coins, Jump, Complete the parkour, reach the end!
[Play Jump And Start on Itch.io](https://mperitv.itch.io/jump-and-start)
## Goal
Collect all the coins, navigate through obstacles, and reach the finish line as fast as you can!

## Controls  
- Move Right: D or Right arrow key  

- Move Left: A or Left arrow key  

- Jump: W, Up arrow key or Space  
## Tech Stack
- Engine: Godot (4.7)  
- Language: GDScript
## Assets
Sprites & Tilemap: [Pixel Platformer by Kenney](https://kenney.nl/assets/pixel-platformer)
